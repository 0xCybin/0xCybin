### MCP Servers

**[Argus](https://github.com/0xCybin/argus)** -- 177-tool MCP server + autonomous AI agent for Discord community management. Moderation, tickets, analytics, trust scoring, raid defense, natural language admin commands. Two-process architecture: MCP server (stdio) + persistent agent with event-driven pipeline.
`TypeScript` `MCP SDK` `discord.js` `SQLite` `Zod`

**[gmail-mcp](https://github.com/0xCybin/gmail-mcp)** -- Gmail MCP server with OAuth2 authentication, automatic token refresh, search, read, send, and threading support.
`TypeScript` `MCP SDK` `Google APIs` `OAuth2`

**[jobs-mcp](https://github.com/0xCybin/jobs-mcp)** -- Multi-source job aggregator. Searches RemoteOK, Hacker News, Arbeitnow, and GitHub. Automated proposal drafting with template scoring.
`TypeScript` `MCP SDK` `Zod`
